# Tournament Bracket Generator

Create a randomized single-elimination tournament and enter each match winner until there is a champion.

## Run

Open this folder in VS Code and run:

```bash
python main.py
```

No extra packages are required.

## Try it

Try 5 players to see how byes work; enter winners until the champion is announced.

## How it works

Players with first-round byes advance automatically. The program uses Python random to shuffle players.
